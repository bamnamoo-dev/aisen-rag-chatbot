User Manual

🏛️ AI-SENSE SMART RAG 챗봇

서울시교육청의 방대한 교육행정 지침서를 인공지능이 실시간 분석하여 신속한 업무 해결책과 정확한 법적 근거를 제공하는 지능형 업무 비서입니다.

🖥️ 화면 레이아웃 및 구성

챗봇 서비스 화면은 업무를 손쉽게 탐색하고 AI와 원활하게 대화할 수 있도록 좌우 2단으로 직관성 있게 구성되었습니다.

구분 주요 화면 구성 사용 목적
좌측 사이드바 • ACTIVE CHANNELS (업무 목록)
• 지침서 개별 다운로드 버튼		 질문하고자 하는 업무 카테고리를 선택하고, 근거 지침서 원본 PDF를 직접 받아봅니다.
우측 메인화면 • 대화형 답변 피드
• 실시간 처리 상태창
• 하단 질문 입력 필드		 궁금한 질문을 입력하고 요약, 분석, 매칭된 실시간 원문 팝업을 확인합니다.

💬 3단계 질문하기 및 활용법

1

업무 카테고리 선택

질문하려는 행정 분야(예: 💼 공무원, 🤝 계약, 💰 예산 등)를 먼저 선택합니다.

  • 선택 시 파란색 카드로 활성화되며, 하단에 다운로드 가능한 지침 목록이 펼쳐집니다.
  • 정확한 답변을 위해 분야 선택 후 대화를 개시하는 것을 추천합니다.
2

질문 입력

메인 화면의 입력창에 자연스러운 어조로 질문을 보냅니다.

  • 질문이 전송되면 AI가 지침을 선별하고 분석하는 흐름이 화면에 실시간으로 보입니다.
  • 지능형 RAG 필터가 작동하여 질문과 무관한 내용은 걷어내고 가장 밀접한 내용만 찾아냅니다.
3

결과 확인 및 연속 대화

AI가 제공하는 체계적인 답변 구조와 근거 자료를 확인합니다.

  • 💡 핵심 요약 (3대 요점): 답변 최상단에 핵심 해결책 3가지 선제 요약
  • 🔍 상세 해설: 유기적으로 엮인 세부 정보 및 참고한 지침 파일/페이지 명시
  • 📍 참고 지침 원문 확인: 답변 하단의 팝오버(Popover) 카드로 실제 지침 원문 즉시 대조
  • 💡 추천 질문: 클릭 한 번으로 관련 내용을 깊이 있게 탐색 가능한 추천 질문 버튼
💡
더 똑똑한 답변을 얻는 질문 요령

단순 키워드 입력("병가")보다 구체적인 상황을 적어주세요. 예컨대 "공무원 일반 병가 연간 일수가 며칠이고, 며칠 이상 사용할 때 진단서가 필요한가요?"라고 구체적으로 적어주실수록 가장 정확한 문서를 매칭하여 오차 없는 답을 돌려줍니다.

⚖️ 교육행정 법령 및 조례 검색

업무 지침의 상위 근거가 되는 대한민국의 법령(시행령, 시행규칙)이나 서울특별시교육청의 조례, 규칙을 직접 조회할 수 있습니다. 검색의 정확성을 높이기 위해 상위법령과 자치법규가 개별 카테고리로 이원화되어 제공됩니다.

⚖️

상위법령 카테고리

중앙 정부의 법률·시행령·시행규칙을 검색합니다. (예: 지방공무원법, 지방계약법, 근로기준법 등)

🏛️

자치법규 카테고리

서울시교육청 고유 조례·시행규칙·규정을 검색합니다. (예: 지방공무원 복무 조례, 학교회계 규칙 등)

💡
선택한 카테고리에 맞춰 질문하기

사이드바에서 [⚖️ 상위법령] 또는 [🏛️ 자치법규]를 선택한 뒤 질문창에 입력해 주세요. 예시: "지방공무원법상 직위해제 기준"(상위법령 선택) 또는 "교육공무직원 채용 조례상 경조사 휴가 기준"(자치법규 선택) 등으로 정확한 관련 조항을 찾아 매칭해 줍니다.

🎨 슬래시 명령어(/) 및 초성 자동완성 활용

질문 입력창에서 카테고리를 직접 지정하여 검색할 수 있는 퀵 명령어와 초성 검색 기능이 탑재되어 있습니다.

/

자동완성 드롭다운 호출

질문 입력창에 슬래시(/)를 입력하면 즉시 전체 카테고리 제안 팝업이 나타납니다.

ㄱ

한글 초성 검색 및 매칭

/ㄱ을 타이핑하면 계약, 감사, 급원, 공무원 등 일치하는 초성 카테고리만 동적으로 필터링됩니다.

  • 키보드 방향키로 제안 목록을 이동하고 엔터(Enter) 또는 마우스 클릭으로 카테고리를 자동 기입합니다.
🎯

강제 라우팅 및 신속 검색

/지출 수의계약 한도와 같이 입력하여 질문하면 AI가 질문의 카테고리를 강제로 '지출' 분야로 타겟팅하여 정밀 탐색합니다.

  • 슬래시가 지정된 질문은 녹색의 '📍 슬래시 지정 결과' 배지와 함께 안전하고 신속하게 처리됩니다.

⚡ 자주 묻는 질문(FAQ) 초고속 답변 매칭

자주 유입되는 행정 실무 질문에 대해 사전에 등록된 검증된 표준 답변(FAQ)을 AI가 즉시 매칭하여 가장 신속하고 정확하게 알려줍니다.

💡

시맨틱 매칭 동작 원리

사용자가 입력한 질문이 사전에 등록된 FAQ와 의미적으로 높은 유사성(85% 이상)을 보이면, AI가 문서를 추가 검색하는 대기 시간 없이 바로 사전 정의된 표준 답변과 추천 질문을 즉각 띄워 응답 속도와 정확도를 극대화합니다.

🔍

유연한 자연어 검색 지원

꼭 등록된 질문 문장과 토씨 하나 틀리지 않고 똑같이 묻지 않아도 괜찮습니다. 비슷한 어조나 단어로 질문해도 AI가 의미의 맥락을 판별해 알아서 표준 답변으로 매칭합니다.

  • 예: 대표 질문이 "1인 수의계약 금액 얼마"로 등록되어 있을 때, "수의계약 한도가 어떻게 돼?" 혹은 "일인 수의계약 기준"이라고 물어도 동일한 표준 답변이 매칭됩니다.
